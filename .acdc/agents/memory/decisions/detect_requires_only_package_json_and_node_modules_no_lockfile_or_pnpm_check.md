## Compiled Truth

Decision: Detect mirrors the pnpm buildpack: package.json plus node_modules.
Why: These two files are what a prebundled app always has.
Rejected: requiring package-lock.json because in npm workspaces the lockfile sits at the monorepo root, not in the deployed module dir; stepping aside when pnpm-lock.yaml or node_modules/.pnpm exists because buildpacks referenced by git URL in mta.yaml skip detect, so the check would add nothing.
Revisit when: the buildpack is installed with `cf create-buildpack` and runs detect alongside other buildpacks.
